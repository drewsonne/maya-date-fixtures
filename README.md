# maya-date-fixtures

Verified, cited test vectors for Maya calendar conversion — Long Count, Calendar Round,
Maya day number, and western dates — as language-agnostic YAML.

Also the documentation hub for the Maya Dates project (ADR 0007): project-wide decisions,
research findings, and work plans.

Every value carries its provenance:

- `attested` — published inscription, table or worked example, cited to author, year, and page or table
- `derived` — hand-calculated or from an independent implementation, derivation shown
- `unverified` — stated from memory, flagged, excluded from any trust gate

A value produced by running an implementation is not admissible at any provenance level.

## Datos de prueba verificados

Vectores de prueba verificados y citados para la conversión del calendario maya — Cuenta
Larga, día maya y fechas occidentales — en YAML independiente del lenguaje.

Cada valor indica su procedencia. Un valor generado ejecutando una implementación no se
admite en ningún nivel de procedencia.

> Terminología pendiente de verificación contra Kettunen y Helmke, *Introducción a los
> Jeroglíficos Mayas*, antes de publicarse. Véase ADR 0008.
